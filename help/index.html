Application Operation
1

Enable Foreground Service

Activate the mascot service from the main application dashboard. A persistent notification keeps the overlay active.

2

Interact via Text or Voice

Tap the floating mascot or use local voice recording. The mascot displays a thinking state (O-O) while rendering streamed responses.

3

Stage 1 vs. Stage 2 Web Search

Stage 1 provides instant local AI answers. If real-time information is required, Stage 2 connects to live web search endpoints.

4

Personality Customization

Choose between Friendly Battu, Sarcastic Ba-2, or define custom personality traits in the Personality screen.
